지식 그래프에서 보여 줄 것
  1. 화살표(남색) = 실제 인용: 문헌고찰(가상) 논문이 다른 논문을 참고문헌에서 인용 → 본문에서 제목이 확인된 것만 선으로 이음
  2. 청록색 선 = 교수님이 만든 연결 (노트-논문, 프로젝트, [[노트 링크]])
  3. 보라색 점(핵심 개념) = 여러 논문이 공유하는 키워드 (예: 비판적 사고, 생성형 AI)
  4. 'AI 관련성 제안 만들기' (의미 검색 색인이 있어야 함) → 금색 점선 = AI 제안
     → 점선을 눌러 '관련 있음 / 관련 없음' 결정: 확인 전까지는 '제안'일 뿐
  5. 노드 검색칸에 '리터러시' 입력 → 해당 논문 강조, 노드 두 번 누르면 논문 열림
