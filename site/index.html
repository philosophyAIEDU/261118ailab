교수님만의 AI 연구실

교수님의 논문과 연구자료를 모으고, 검색하고, 비교하고, 연결하세요.

흩어진 PDF 논문을 내 컴퓨터 안의 연구실에 모으면, AI가 실제 논문을 근거로 답하고, 근거를 누르면 해당 PDF 쪽이 열립니다. AI는 내 컴퓨터의 로컬 AI와 Gemini API 무료 티어 중에서 고를 수 있습니다.

⊞Windows용 다운로드확인 중… ⌘macOS용 다운로드확인 중…

최신 버전을 확인하는 중… · Windows 10/11 · macOS 12 이상 (Apple 칩·Intel)

화면 예시는 시연용 가상 데모 연구실입니다. 표시된 논문·저자·수치는 실제 논문이 아닙니다.

이런 교수님께

흩어진 연구자료를 평생 쓰는 지식 자산으로

다운로드 폴더, 이메일 첨부, 클라우드 드라이브에 흩어진 논문을 한곳에 모으고, 몇 년 전에 읽은 논문의 그 문장까지 다시 찾아 연구로 이어 가세요.

📚

“그 논문 어디 있었더라?”

제목이 기억나지 않아도 “AI 의존과 메타인지의 관계” 같은 내용으로 찾고, 해당 쪽을 바로 엽니다.

⚖

“연구 방법이 어떻게 달랐지?”

논문 2~10편의 연구 목적·대상·표본·방법·결과·한계를 한 표로 비교하고, 칸마다 원문 쪽을 확인합니다.

🔒

“연구자료를 외부 AI에 올려도 될까?”

AI가 교수님 컴퓨터 안에서만 실행됩니다. 미발표 원고와 연구 메모도 밖으로 나가지 않습니다.

주요 기능

논문 관리부터 문헌고찰 준비까지, 한 프로그램에서

모든 기능은 교수님이 등록한 실제 자료와 연결됩니다. 가짜 결과나 꾸며낸 인용을 보여 주지 않습니다.

⇣

논문 등록

PDF·Word·TXT·Markdown·BibTeX·RIS를 끌어다 놓거나 폴더째 등록합니다. 같은 파일은 자동으로 걸러 내고, 진행률을 보여 주며, 실패한 파일은 다시 처리할 수 있습니다. 원본 파일은 수정하지 않습니다.

🏷

서지정보 자동 추출

제목·저자·연도·DOI·초록·키워드를 문서에 실제로 있는 정보만 가져오고, 칸마다 어디서 가져왔는지 표시합니다. 추정한 값은 “확인 필요”로 알려 드리며 언제든 고칠 수 있습니다.

⌕

AI 연구 검색

자연어로 질문하면 키워드·의미·하이브리드 검색으로 관련 문단을 찾고, AI가 그 문단만 근거로 답합니다. 답변의 [S1] 표시를 누르면 원문과 PDF 쪽으로 이동합니다.

▤

PDF 뷰어

쪽 이동, 확대·축소, 문서 안 찾기, 하이라이트·메모·북마크. AI 답변의 근거를 열면 해당 쪽에서 근거 문단을 노란색으로 표시합니다.

⇆

논문 비교표

연구 목적·연구 질문·이론적 배경·방법·대상·표본 크기·분석 방법·주요 결과·한계·후속 연구 제안을 비교합니다. 원문에서 확인되지 않는 칸은 추측하지 않고 비워 둡니다.

✎

연구 노트

Markdown으로 쓰고 자동 저장됩니다. 논문·프로젝트·태그를 연결하고, [[노트 제목]]으로 노트끼리 이으면 백링크가 생깁니다. AI 초안은 교수님이 검토한 뒤에만 저장됩니다.

✣

지식 그래프

논문·노트·주제·핵심 개념·프로젝트의 관계를 한눈에 봅니다. 본문에서 확인된 실제 인용과 AI가 제안한 관련성(점선)을 분명히 구분합니다.

☰

문헌고찰 지원

선택한 논문으로 주제별 분류, 공통 연구 흐름, 방법·결과 비교, 한계, 연구 공백 후보, 개요 초안을 만듭니다. 참고문헌은 등록된 서지정보로만 작성합니다.

⇡

내보내기

논문 목록·비교표·노트·문헌고찰·프로젝트 보고서를 Word·Excel·CSV·Markdown·TXT·BibTeX로 저장합니다. 출처 쪽과 검증 상태가 함께 기록됩니다.

⇄

Zotero·Obsidian 연동

Zotero에서 내보낸 BibTeX·RIS로 서지정보를 가져오고 중복을 정리합니다. 연구 노트는 YAML·태그·논문 링크를 갖춘 Obsidian 보관함으로 내보내며 기존 파일은 덮어쓰지 않습니다.

◈

연구 프로젝트

주제별로 논문과 노트를 묶고, 프로젝트 논문만 대상으로 질문하거나 비교하고, 보고서로 내보냅니다.

✦

AI 선택: 로컬 또는 Gemini 새 기능

내 컴퓨터에서 실행되는 로컬 AI(모델 추천·내려받기)와 Google Gemini API 무료 티어(gemini-3.5-flash-lite / gemini-3.8-flash) 중에서 고릅니다. API 키는 직접 넣고, 오늘 쓴 무료 사용량을 모델별로 보여 드립니다.

⟳

백업·복원·자동 업데이트

연구실 전체를 백업하고(암호화 선택), 검증한 뒤 복원합니다. 새 버전은 프로그램 안에서 확인하고, 전자서명을 검증한 파일만 설치합니다.

화면 둘러보기

실제 프로그램 화면

아래는 실제 프로그램을 실행해 찍은 화면입니다. 시연용 가상 데모 자료를 사용했고, AI 답변은 시험용 응답입니다.

AI 연구 검색 — 답변의 S1·S2 표시가 실제 원문과 연결됩니다. 검색 결과에 없는 출처 표기와 확인되지 않은 인용은 검증 단계에서 제거되고, 제거 사실이 표시됩니다.

믿을 수 있는 AI 답변

AI가 존재하지 않는 논문을 만들어 내지 않도록

답변의 모든 출처는 실제로 검색된 문서와 쪽 번호로만 만듭니다. 근거가 부족하면 지어내지 않고 “현재 등록된 연구자료에서 충분한 근거를 찾지 못했습니다.”라고 말합니다.

  1. 질문 분석검색어를 뽑고 질문의 의미를 숫자 벡터로 바꿉니다.
  2. 관련 문단 검색키워드 검색과 의미 검색을 함께 사용합니다(한국어 부분 일치 지원).
  3. 재정렬두 결과를 합쳐 순위를 매기고, 한 논문이 결과를 독점하지 않게 합니다.
  4. 근거 충분성 판단관련 문단이 없으면 AI를 부르지 않고 근거 부족을 알립니다.
  5. 답변 생성로컬 AI가 주어진 문단만 근거로, 문장마다 [S번호]를 붙여 답합니다.
  6. 인용 검증실제 문단이 아닌 번호, 등록 자료에 없는 (저자, 연도) 인용은 제거합니다.
  7. 원문 연결각 근거는 논문과 PDF 쪽 번호를 가지며, 누르면 그 쪽이 열립니다.
AI 답변 (예시) AI 생성 · 검토 필요

원문 (예시) 근거 확인

사전 점수를 통제한 후 실험집단의 비판적 사고 성향 사후 점수는 비교집단보다 유의하게 높았다…

S1 · 「…글쓰기 수업이 대학생의 비판적 사고 성향에 미치는 영향」 · PDF 4쪽 열기 →

인용 검증은 출처가 실제로 존재하는지와 답변 문장이 원문과 대응하는지를 확인합니다. 요약의 의미까지 완벽하게 보장하지는 않으므로, AI가 만든 답변·비교표·초안은 반드시 원문과 대조해 검토해 주세요. 학술지와 소속 기관의 생성형 AI 활용 규정도 함께 확인해 주세요.

자료 보호

연구자료는 교수님 컴퓨터에만

로컬 우선 저장

  • PDF 사본, 서지정보, 노트, 프로젝트, 비교 결과, 검색 색인, 설정을 문서/PhilosophyResearchHub 폴더에 저장합니다.
  • 프로그램 파일과 분리되어 있어 업데이트·재설치·제거 후에도 그대로 남습니다.
  • 원본 PDF는 읽기만 하며 수정·삭제하지 않습니다.

기본은 로컬 AI, Gemini는 선택

  • 기본 설정은 이 컴퓨터에서 실행되는 로컬 AI(Ollama)입니다. 연구자료가 밖으로 나가지 않습니다.
  • Gemini API는 교수님이 직접 고르고, 전송 내용·비용 안내에 동의하고, 키를 넣어야만 사용합니다. 이때도 질문과 관련 발췌 문단만 보내고 PDF 전체·노트는 보내지 않습니다.
  • Gemini 무료 티어는 Google이 입력 내용을 제품 개선에 쓸 수 있으므로, 민감한 자료에는 로컬 AI를 권장합니다.

인터넷을 쓰는 경우

  • AI 모델 내려받기 (Ollama가 ollama.com에서)
  • 업데이트 확인·설치 (GitHub Releases, 버전 정보만)
  • Gemini API를 선택한 경우의 답변 생성

앞의 두 경우에는 연구자료가 전송되지 않습니다. 계정 가입, 사용 기록 수집도 없습니다. Gemini API 키는 운영체제 보안 저장소에만 보관합니다.

문서 속 숨은 지시문 방어

PDF 안에 “이전 지시를 무시하라” 같은 문장이 있어도 AI가 따르지 않도록 자료와 지시를 분리하고, 의심 문장이 있는 출처에는 “주의” 표시를 합니다.

로컬 AI를 쓴다고 보안이 자동으로 완벽해지지는 않습니다. 컴퓨터 암호, 디스크 암호화, 백업 파일 보관에도 신경 써 주세요.

요구 사양

어떤 컴퓨터에서 쓸 수 있나요?

논문 등록·검색·PDF 보기·노트·내보내기·백업은 일반 사무용 컴퓨터에서 동작합니다. AI 기능은 메모리가 클수록 정확하고 빠릅니다. 프로그램이 사양을 확인해 맞는 모델을 추천합니다.

용량은 Ollama 기본 태그의 근사값이며, 실제 속도는 컴퓨터 상태에 따라 다릅니다. 저장 공간은 프로그램 약 50MB + 논문 + AI 모델 용량이 필요합니다.

설치 방법

3단계면 준비됩니다

1

프로그램 설치

Windows: 내려받은 …setup.exe를 실행합니다. 관리자 권한 없이 현재 사용자에게 설치되고, 시작 메뉴에 “교수님만의 AI 연구실”이 생깁니다.

macOS: .dmg를 열고 앱을 “응용 프로그램” 폴더로 끌어다 놓습니다.

2

AI 고르기

로컬 AI: Ollama를 설치하고 실행합니다.
Gemini API: Google AI Studio에서 무료 API 키를 만듭니다.

3

설정에서 연결

설정 → AI 모델 → 답변 생성 AI 선택에서 로컬 AI 모델을 내려받아 고르거나, Gemini를 고르고 안내에 동의한 뒤 키를 붙여 넣습니다.

Windows에서 “Windows의 PC 보호” 경고가 나와요

현재 설치 파일은 코드 서명 인증서가 적용되기 전이라 Microsoft SmartScreen이 경고할 수 있습니다. 이 사이트(또는 공식 GitHub)에서 받은 파일이 맞다면 추가 정보 → 실행을 누르면 설치됩니다. 코드 서명은 정식 배포 전에 적용할 예정입니다.

macOS에서 “확인되지 않은 개발자” 경고가 나와요

Apple 공증 전 버전에서는 경고가 나타날 수 있습니다. Finder에서 앱을 Control-클릭(오른쪽 클릭) → 열기 → 열기를 누르거나, 시스템 설정 → 개인정보 보호 및 보안에서 “그래도 열기”를 선택하세요.

프로그램을 지우면 연구자료도 지워지나요?

아니요. 연구자료는 프로그램과 분리된 문서/PhilosophyResearchHub 폴더에 있어 제거해도 자동으로 삭제되지 않습니다. 다시 설치하면 그대로 이어서 쓸 수 있습니다.

사용 방법

처음부터 하나씩

처음이라면 대시보드의 데모 연구실 열어 보기로 가상 자료를 먼저 둘러보세요. 데모는 내 연구실과 다른 폴더에 만들어집니다.

1. 논문 등록하기
  1. 내 논문에서 파일 등록 또는 폴더 등록을 누르거나, PDF를 창으로 끌어다 놓습니다.
  2. 등록 결과에서 등록·중복·실패를 확인합니다. 실패한 파일은 다시 처리를 누릅니다.
  3. 논문을 눌러 서지정보를 확인합니다. “자동 추정 — 확인 필요” 표시가 있는 칸은 확인해 고쳐 주세요. 고친 값은 이후 덮어쓰이지 않습니다.
  4. 태그·연구 분야·개인 메모를 적어 두면 검색과 지식 그래프에 반영됩니다.

“글자 없음 (OCR 필요)”는 스캔 이미지 PDF입니다. Acrobat의 텍스트 인식, macOS 미리보기, OCRmyPDF 등으로 문자 인식 후 다시 등록하세요. HWP 파일은 PDF로 저장한 뒤 등록합니다.

2. AI에게 질문하기 (AI 연구 검색)
  1. AI 연구 검색에 질문을 씁니다. 예: “내가 저장한 논문 중 생성형 AI와 비판적 사고의 관계를 다룬 연구를 찾아줘.”
  2. 검색 방식은 하이브리드를 권장합니다. 범위를 프로젝트나 선택한 논문으로 좁힐 수 있습니다.
  3. 답변의 S1을 누르면 근거 원문으로, PDF n쪽 열기를 누르면 실제 쪽으로 이동합니다.
  4. “근거 확인”은 답변 문장과 원문이 잘 대응한다는 뜻, “원문 확인 필요”는 직접 대조가 필요하다는 뜻입니다.

“AI 답변 생성”을 끄면 AI 없이 원문 검색 결과만 볼 수 있습니다. 검색 결과는 Word·Markdown으로 저장됩니다.

3. PDF 읽으며 표시하기
  • 위쪽에서 쪽 번호 입력, 확대·축소, 폭 맞춤, 북마크를 합니다.
  • 글자를 드래그해 선택하면 하이라이트 또는 메모를 남길 수 있습니다. 원본 PDF는 바뀌지 않습니다.
  • 오른쪽 찾기에서 문서 안의 단어를 찾고, 주석에서 하이라이트·메모를 모아 봅니다.
4. 논문 비교표 만들기
  1. 논문 비교에서 2~10편을 고릅니다.
  2. 비교 항목(기본 10개)을 고르고 비교표 만들기를 누릅니다. 논문 수에 따라 몇 분 걸릴 수 있습니다.
  3. 칸의 p.3을 누르면 근거 쪽이 열립니다. “원문에서 확인되지 않음”은 AI가 근거를 찾지 못한 칸입니다.
  4. Excel(근거 원문 시트 포함)·Word·Markdown·CSV로 저장합니다.
5. 연구 노트와 프로젝트
  • 새 노트를 만들고 제목을 쓰면 자동 저장됩니다. Markdown으로 쓰고 미리보기로 확인합니다.
  • [[다른 노트 제목]]으로 연결하면 상대 노트에 백링크가 표시됩니다.
  • AI 초안으로 내용 추가: 논문을 고르면 근거 표시가 달린 초안이 만들어지고, 검토했습니다 — 노트에 저장을 눌러야 저장됩니다.
  • 연구 프로젝트에서 논문과 노트를 묶고, 프로젝트 보고서를 Word로 내보냅니다.
6. 지식 그래프 보기
  • 화살표: 본문·참고문헌에서 DOI나 제목이 확인된 실제 인용
  • 청록 선: 교수님이 만든 연결(노트–논문, 프로젝트, 노트 링크)
  • 금색 점선: AI 제안 — 눌러서 “관련 있음” 또는 “관련 없음”을 고르면 됩니다.
  • 연한 선: 같은 주제·공통 키워드

끌어서 이동, 휠로 확대·축소, 노드를 두 번 누르면 자료가 열립니다.

7. 문헌고찰 개요 만들기

문헌고찰 지원에서 논문 2~15편과 주제를 정하고 개요 초안 만들기를 누르면 주제별 분류, 공통 연구 흐름, 방법·결과 비교, 한계, 연구 공백 후보, 절 구성안, 참고문헌이 만들어집니다. 최종 원고가 아닌 검토용 초안이며, 참고문헌은 등록된 서지정보로만 작성됩니다.

8. Zotero에서 가져오기 · Obsidian으로 내보내기

Zotero: 컬렉션 오른쪽 클릭 → 컬렉션 내보내기 → BibTeX 또는 RIS(PDF도 함께라면 “파일 내보내기” 체크) → 프로그램의 Zotero 가져오기에서 선택. 같은 논문이 있으면 비어 있는 서지정보만 채우고, Zotero 데이터베이스는 건드리지 않습니다.

Obsidian: 내보내기 → Obsidian 폴더로 내보내기에서 보관함 폴더를 고르면 프로젝트별 노트와 논문 노트가 만들어집니다. 이미 있는 파일은 덮어쓰지 않습니다.

9. 백업과 복원
  1. 설정 → 연구실 자료·백업 → 백업 만들기에서 PDF 포함 여부와 (선택) 암호를 정하고 저장 위치를 고릅니다. 백업은 만든 직후 자동으로 검증됩니다.
  2. 복원은 백업에서 복원 → 백업 확인으로 내용과 현재 연구실과의 차이를 본 뒤 진행합니다. 현재 데이터는 복원 직전에 안전 사본으로 보관됩니다.

암호를 잊으면 암호화된 백업은 복구할 수 없습니다. 외장 디스크 등에 정기적으로 백업하세요.

업데이트

새 버전은 프로그램 안에서

“새로운 업데이트가 있습니다.”

프로그램을 실행하면 새 버전을 확인하고 현재·최신 버전, 개선된 기능, 수정된 오류, 파일 크기를 보여 드립니다. 업데이트 설치 또는 나중에를 고르세요. 안정 버전과 시험판(베타) 채널을 선택할 수 있습니다.

업데이트해도 자료는 그대로

설치 전에 연구실 데이터베이스의 안전 사본을 만들고, 개발자의 전자서명을 검증한 파일만 설치합니다. 자료 형식이 바뀌는 버전은 변환 전에 자동으로 백업합니다.

자주 묻는 질문

궁금한 점

정말 무료인가요?

네. 필로소피 AI 교육이 MIT 라이선스로 무료 제공합니다. AI 모델도 Ollama를 통해 무료로 내려받는 공개 모델을 사용합니다(모델마다 라이선스가 다르며, 프로그램에서 표시합니다).

Gemini API는 어떻게 쓰나요? 정말 무료인가요?

Google AI Studio에서 Google 계정으로 API 키를 만들어 설정 → AI 모델에 붙여 넣으면 됩니다. 결제 정보를 연결하지 않은 키는 무료 티어로 동작하며 요금이 청구되지 않습니다. 대신 하루·분당 사용 한도가 있고(한국 시간 오후 4~5시 초기화), 무료 티어에서는 Google이 입력 내용을 제품 개선에 사용할 수 있습니다. 결제를 연결한 프로젝트의 키를 쓰면 요금이 나올 수 있습니다.

인터넷 없이도 쓸 수 있나요?

로컬 AI를 쓰면 네. AI 모델을 한 번 내려받은 뒤에는 모든 기능이 인터넷 없이 동작합니다. Gemini API를 선택한 경우에는 AI 답변에 인터넷이 필요합니다.

AI 없이도 쓸 수 있나요?

네. Ollama가 없어도 논문 등록, 서지정보 정리, 키워드 검색, PDF 보기·주석, 노트, 프로젝트, 지식 그래프(AI 제안 제외), 내보내기, 백업을 사용할 수 있습니다.

한국어 논문도 잘 찾나요?

한국어는 띄어쓰기 단위로만 찾으면 “비판적사고는” 같은 표현에서 “비판적”을 놓치기 쉬워, 두 글자 단위로 색인해 부분 일치도 찾을 수 있게 했습니다. 의미 검색에는 다국어 임베딩 모델(bge-m3)을 추천합니다.

논문을 몇 편까지 넣을 수 있나요?

정해진 상한은 없습니다. 시험에서 120편(240쪽)을 약 13초에 등록했고, 키워드 검색은 한 번에 수 밀리초 안에 끝났습니다. 수천 편 규모는 아직 따로 시험하지 않았습니다.

AI 답변을 논문에 그대로 써도 되나요?

권하지 않습니다. AI가 만든 답변·비교표·초안은 검토용입니다. 반드시 원문과 대조하고, 학술지·소속 기관의 생성형 AI 활용 규정에 따라 사용 사실을 밝혀 주세요.

저작권이 있는 논문 PDF를 넣어도 되나요?

프로그램은 PDF를 교수님 컴퓨터 안에만 보관하고 외부로 보내지 않습니다. 개인 연구 목적의 이용 범위와 각 출판사의 이용 조건을 지켜 사용해 주세요.

다른 컴퓨터로 옮기려면요?

백업 만들기(PDF 포함)로 만든 파일을 새 컴퓨터에서 백업에서 복원하면 됩니다. 연구실 폴더를 통째로 복사한 뒤 설정 → 다른 연구실 폴더 열기로 열어도 됩니다.

Linux도 지원하나요?

현재 정식 지원 대상은 Windows와 macOS입니다. Linux는 개발·시험용으로만 빌드하고 있습니다.
