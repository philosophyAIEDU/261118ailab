# 사용 설명서 — 교수님만의 AI 연구실

> 교수님의 논문과 연구자료를 모으고, 검색하고, 비교하고, 연결하세요.

## 1. 처음 시작하기
1. 프로그램을 실행하면 **대시보드**가 열립니다. 연구 자료는 `문서/PhilosophyResearchHub` 폴더(“연구실”)에 저장됩니다.
2. 처음이라면 **데모 연구실 열어 보기**로 가상 자료(논문 12편, 프로젝트, 노트)를 둘러볼 수 있습니다. 데모 자료는 실제 논문이 아니며, 내 연구실과 별도 폴더에 만들어집니다. **설정 → 연구실 자료·백업 → 기본 연구실 열기**로 돌아옵니다.
3. AI 기능(AI 검색·비교·노트 초안·문헌고찰)을 쓰려면:
   - [ollama.com](https://ollama.com/download)에서 **Ollama**를 설치하고 실행합니다.
   - **설정 → AI 모델**에서 추천 모델(예: 답변 생성 `qwen3:8b`, 임베딩 `bge-m3`)을 **내려받기** 합니다.
   - **역할별 모델 선택**에서 답변 생성 모델과 임베딩 모델을 고르고, **의미 검색 색인 만들기**를 누릅니다.
   - AI 없이도 논문 등록·키워드 검색·PDF 보기·노트·내보내기·백업은 사용할 수 있습니다.

## 2. 논문 등록 (내 논문)
- **파일 등록** / **폴더 등록** 버튼, 또는 PDF를 창으로 **끌어다 놓기**. 여러 파일·하위 폴더도 한 번에 등록됩니다.
- 지원 형식: PDF, Word(.docx), TXT, Markdown, BibTeX(.bib), RIS(.ris). HWP는 PDF로 저장 후 등록하세요.
- 같은 파일은 다시 등록되지 않습니다(중복). 원본 파일은 읽기만 하고, 연구실에 사본을 저장합니다.
- 제목·저자·연도·DOI·초록·키워드는 **문서에 실제로 있는 정보만** 가져옵니다. 각 칸 아래 “출처”에서
  `자동 추정 — 확인 필요`라고 표시된 값은 꼭 확인해 고쳐 주세요. 고친 값은 “직접 입력”으로 표시되고 이후 덮어쓰이지 않습니다.
- “글자 없음 (OCR 필요)”: 스캔 이미지 PDF입니다. Acrobat의 텍스트 인식, macOS 미리보기, OCRmyPDF 등으로 문자 인식 후 다시 등록하세요.
- “본문 추출 실패”: **본문 다시 추출** 버튼으로 재처리할 수 있습니다.
- **연구실에서 삭제**는 연구실 안의 기록과 사본만 지웁니다. 컴퓨터의 원본 파일은 그대로입니다.

## 3. PDF 보기
- 논문 정보에서 **PDF 열기**. 위쪽에서 쪽 이동, 확대·축소, 폭 맞춤, 북마크를 할 수 있습니다.
- 글자를 드래그해 선택하면 **하이라이트** 또는 **메모**를 남길 수 있습니다(원본 PDF는 바뀌지 않음).
- 오른쪽 **찾기** 탭에서 문서 안의 단어를 찾습니다.
- AI 답변의 출처에서 열면 **AI 출처** 탭에 근거 문단이 표시되고, 해당 쪽에서 일치하는 부분이 노란색으로 표시됩니다.

## 4. AI 연구 검색
- 예: “내가 저장한 논문 중 생성형 AI와 비판적 사고의 관계를 다룬 연구를 찾아줘.”
- 검색 방식: **하이브리드**(권장) / 의미 검색 / 키워드. “AI 답변 생성”을 끄면 원문 검색 결과만 봅니다.
- 범위를 프로젝트 논문이나 선택한 논문으로 좁힐 수 있습니다.
- 답변의 **S1, S2** 표시를 누르면 해당 원문으로 이동하고, **PDF n쪽 열기**로 실제 쪽을 확인합니다.
  - `근거 확인`: 답변 문장과 원문이 잘 대응합니다. / `원문 확인 필요`: 실제 원문이지만 대응이 약합니다.
  - 실제 검색 결과에 없는 출처 표시나 등록 자료에 없는 인용은 자동으로 제거되고, 제거 사실이 표시됩니다.
- 근거가 부족하면 “현재 등록된 연구자료에서 충분한 근거를 찾지 못했습니다.”라고 안내합니다.
- **AI 답변은 검토용입니다.** 반드시 원문과 대조해 주세요.

## 5. 논문 비교
- 2~10편을 고르고 비교 항목(연구 목적·질문·이론적 배경·방법·대상·표본 크기·분석 방법·주요 결과·한계·후속 연구 제안)을 고른 뒤 **비교표 만들기**.
- 각 칸의 **p.n**을 누르면 근거 쪽이 열립니다. 원문에서 확인되지 않는 항목은 “원문에서 확인되지 않음”으로 비워 둡니다.
- Excel·Word·Markdown·CSV로 저장할 수 있습니다(근거 원문 시트 포함).

## 6. 연구 노트
- **새 노트** → 제목을 쓰면 자동 저장됩니다. Markdown으로 쓰고 **미리보기**로 확인합니다.
- `[[다른 노트 제목]]`으로 노트를 연결하면 상대 노트에 **백링크**가 생깁니다.
- 관련 논문·연구 프로젝트·태그를 연결할 수 있습니다.
- **AI 초안으로 내용 추가**: 논문을 고르면 AI가 근거 표시가 달린 초안을 만듭니다. 내용을 검토한 뒤 **검토했습니다 — 노트에 저장**을 눌러야 저장됩니다.

## 7. 연구 프로젝트 · 지식 그래프
- 프로젝트에 논문과 노트를 묶고, 프로젝트 논문만 대상으로 질문하거나 **프로젝트 보고서**(Word·Markdown)를 만듭니다.
- 지식 그래프의 선 종류: **실제 인용**(본문·참고문헌에서 DOI 또는 제목 확인, 화살표) / 교수님 연결 / **AI 제안**(점선, 확인 전) / 동일 주제 / 공통 키워드.
- **AI 관련성 제안 만들기** 후 점선을 눌러 “관련 있음(내 연결로)” 또는 “관련 없음”을 고릅니다. 노드를 두 번 누르면 자료가 열립니다.

## 8. 문헌고찰 지원
- 논문 2~15편과 주제를 정하고 **개요 초안 만들기**. 공통 연구 흐름, 방법·결과 비교, 한계, **연구 공백 후보**, 절 구성안을 만듭니다.
- 참고문헌은 등록된 서지정보로만 만듭니다. 연구 공백은 선택한 자료 범위에서 나온 후보일 뿐입니다.
- 학술지·소속 기관의 생성형 AI 활용 규정을 확인하고, 필요하면 AI 사용 사실을 밝혀 주세요.

## 9. Zotero · Obsidian
- Zotero: 컬렉션 오른쪽 클릭 → 내보내기 → BibTeX 또는 RIS (PDF도 등록하려면 “파일 내보내기” 체크) → **Zotero 가져오기**에서 파일 선택. Zotero 내부 데이터베이스는 건드리지 않습니다.
- Obsidian: **내보내기 → Obsidian 폴더로 내보내기** → 보관함 폴더 선택. `교수님만의 AI 연구실/` 아래에 프로젝트별 노트와 논문 노트가 만들어지며, 이미 있는 파일은 덮어쓰지 않습니다.

## 10. 내보내기
논문 목록, 연구 노트, 비교표, 문헌고찰, 프로젝트 보고서, AI 검색 결과를 Word·Excel·CSV·Markdown·TXT·BibTeX로 저장합니다. 출처와 검증 상태가 함께 기록됩니다.

## 11. 백업과 복원 (설정 → 연구실 자료·백업)
- **백업 만들기**: PDF 사본 포함 여부와 (선택) 암호를 정한 뒤 저장 위치를 고릅니다. 만든 뒤 자동으로 검증합니다. 암호를 잊으면 복구할 수 없습니다.
- **백업에서 복원**: 백업 파일 선택 → **백업 확인**(내용·검증 결과·현재 연구실과의 차이 표시) → **복원**. 현재 데이터베이스는 복원 직전에 `backups` 폴더에 안전 사본으로 보관됩니다.
- 외장 디스크나 학교 저장소에 정기적으로 백업하세요.

## 12. 업데이트
- 실행할 때 새 버전이 있으면 “새로운 업데이트가 있습니다.” 창이 뜹니다. 현재·최신 버전, 개선된 기능, 수정된 오류, 파일 크기를 확인하고 **업데이트 설치** 또는 **나중에**를 고릅니다.
- 설치 전에 연구실 데이터베이스의 안전 사본을 만들고, 전자서명을 검증한 파일만 설치합니다. 연구자료는 업데이트 후에도 그대로입니다.
- **설정 → 업데이트**에서 채널(안정/베타)과 실행 시 확인 여부를 바꿀 수 있습니다.

## 13. 개인정보와 보안
- 연구자료는 이 컴퓨터에만 저장되고, AI는 이 컴퓨터의 Ollama만 사용합니다. 클라우드 AI는 사용하지 않습니다.
- 인터넷은 AI 모델 내려받기와 업데이트 확인에만 쓰입니다.
- 로컬에서 처리한다고 해서 보안이 자동으로 완벽해지지는 않습니다. 컴퓨터 암호, 디스크 암호화, 백업 파일 보관에 유의하세요.

## 14. 유튜브 시연 순서 (데모 연구실)
1. 프로그램 실행 → 시작 화면·대시보드
2. 내 논문 → PDF 여러 편 끌어다 놓기(또는 데모 연구실)
3. AI 연구 검색: “내가 저장한 논문 중 생성형 AI와 비판적 사고의 관계를 다룬 연구를 찾아줘.”
4. S1 근거 → PDF 쪽 열기로 실제 근거 확인
5. 논문 비교 → 3~4편 비교표
6. 지식 그래프 → 실제 인용(화살표)과 AI 제안(점선)
7. 연구 노트 → AI 초안 검토 후 저장
8. 내보내기 → Word·Excel 저장
9. 무료 다운로드 안내: GitHub Releases

## 15. 문제 해결
| 증상 | 해결 |
|---|---|
| “로컬 AI(Ollama)에 연결할 수 없습니다” | Ollama 실행 여부 확인 → 설정 → AI 모델 → 다시 확인 |
| “메모리가 부족합니다” | 설정 → AI 모델에서 더 가벼운 모델 선택, 메모리에 올라간 모델 “모델 중지”, 다른 프로그램 종료 |
| 의미 검색이 키워드로 바뀜 | 임베딩 모델 선택 후 “의미 검색 색인 만들기” |
| 연구실이 열리지 않음 | 설정 → 연구실 자료에서 폴더 다시 선택, 또는 백업에서 복원 |
| 한글이 깨진 TXT | UTF-8 또는 EUC-KR로 저장된 파일인지 확인 |
