## 교수님만의 AI 연구실 v0.1.0-preview.1 (미리보기 시험판)

처음 공개하는 미리보기 판입니다. 기능을 먼저 써 보시고 의견을 주세요.

### 개선된 기능
- 논문 등록(PDF·DOCX·TXT·Markdown·BibTeX·RIS), 폴더·끌어다 놓기 일괄 등록, 중복 검사, 서지정보 자동 추출(출처 표시)
- PDF 뷰어: 쪽 이동, 확대·축소, 찾기, 하이라이트·메모·북마크, AI 근거 쪽 표시
- AI 연구 검색(로컬 Ollama): 키워드·의미·하이브리드 검색, 원문 근거와 PDF 쪽 연결, 인용 검증
- 논문 비교표, 문헌고찰 개요 초안, 연구 노트(백링크), 연구 프로젝트, 지식 그래프
- Word·Excel·CSV·Markdown·TXT·BibTeX 내보내기, Zotero 가져오기, Obsidian 내보내기
- 연구실 백업·검증·복원(선택적 암호화), 가상 데모 연구실

### 알아 두실 점
- **앱 내부 자동 업데이트를 받지 않는 판입니다.** 다음 버전은 이 페이지나 소개 사이트에서 직접 내려받아 설치해 주세요. 연구자료(문서/PhilosophyResearchHub)는 그대로 유지됩니다.
- 코드 서명·Apple 공증 전이라 설치할 때 Windows SmartScreen 또는 macOS “확인되지 않은 개발자” 경고가 나타날 수 있습니다. (Windows: 추가 정보 → 실행 / macOS: Control-클릭 → 열기)
- AI 기능은 [Ollama](https://ollama.com/download) 설치 후 프로그램의 설정 → AI 모델에서 모델을 내려받아야 사용할 수 있습니다.
- 실제 AI 모델(예: qwen3:8b)과의 답변 품질은 아직 충분히 검증하지 않았습니다. AI 결과는 반드시 원문과 대조해 검토해 주세요.
- 파일 무결성은 함께 올린 `SHA256SUMS.txt`로 확인할 수 있습니다.
