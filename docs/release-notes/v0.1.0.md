## 교수님만의 AI 연구실 v0.1.0

### 개선된 기능
- **AI 선택: 로컬 AI(Ollama) 또는 Gemini API** — 설정 > AI 모델에서 고를 수 있습니다. 로컬 AI 모델은 프로그램 안에서 추천받고 내려받습니다.
- **Gemini API 무료 티어 지원** — gemini-3.5-flash-lite / gemini-3.8-flash, 직접 넣은 API 키는 운영체제 보안 저장소에 보관, 데이터 전송 안내 동의 후 사용
- **하루 무료 사용량 표시** — 모델별 오늘 요청 수/하루 한도, 토큰, 초기화 시각(한국 시간), 분당 한도 자동 조절
- 논문 등록(PDF·DOCX·TXT·Markdown·BibTeX·RIS), 중복 검사, 서지정보 자동 추출(출처 표시)
- PDF 뷰어: 쪽 이동, 확대·축소, 찾기, 하이라이트·메모·북마크, AI 근거 쪽 표시
- AI 연구 검색: 키워드·의미·하이브리드 검색, 원문 근거와 PDF 쪽 연결, 인용 검증
- 논문 비교표, 문헌고찰 개요 초안, 연구 노트(백링크), 연구 프로젝트, 지식 그래프
- Word·Excel·CSV·Markdown·TXT·BibTeX 내보내기, Zotero 가져오기, Obsidian 내보내기
- 연구실 백업·검증·복원(선택적 암호화), 앱 내부 자동 업데이트(이 버전부터)

### 수정된 오류
- 첫 정식 버전입니다. 미리보기 시험판(v0.1.0-preview.1)을 쓰셨다면 이 버전을 직접 내려받아 설치해 주세요. 연구자료는 그대로 유지됩니다. 이후 버전부터는 프로그램 안에서 자동으로 업데이트됩니다.

### 알아 두실 점
- 코드 서명·Apple 공증 전이라 설치 시 운영체제 경고가 나타날 수 있습니다.
- Gemini 무료 티어는 Google이 입력 내용을 제품 개선에 사용할 수 있습니다. 민감한 자료는 로컬 AI를 사용하세요.
- 무료 사용량은 이 컴퓨터에서 보낸 요청을 센 추정치이며, 한도 기본값(3.8 Flash 하루 20회, 3.5 Flash-Lite 하루 500회)은 공개 자료 기준입니다. Google AI Studio에서 실제 값을 확인해 주세요.
