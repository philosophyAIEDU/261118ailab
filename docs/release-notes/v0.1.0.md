## 교수님만의 AI 연구실 v0.1.0 (첫 공개 시험 버전)

### 개선된 기능
- 논문 등록(PDF·DOCX·TXT·Markdown·BibTeX·RIS), 중복 검사, 서지정보 자동 추출(출처 표시)
- PDF 뷰어: 쪽 이동, 확대·축소, 찾기, 하이라이트·메모·북마크
- AI 연구 검색: 키워드·의미·하이브리드 검색, 원문 근거와 PDF 쪽 연결, 인용 검증
- 논문 비교표, 문헌고찰 개요 초안, 연구 노트(백링크), 연구 프로젝트, 지식 그래프
- Word·Excel·CSV·Markdown·TXT·BibTeX 내보내기, Obsidian 내보내기
- 연구실 백업·검증·복원(선택적 암호화), 앱 내부 업데이트
